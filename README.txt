FREE HOSTING WITH GITHUB PAGES
1. Sign in to https://github.com/ and create a NEW PUBLIC repository named vizora-studio (or another available name).
2. Upload index.html, privacy.html, and vizora-logo.png to the repository root.
3. Open Settings > Pages.
4. Under Build and deployment choose Deploy from a branch; choose main and /(root); click Save.
5. Wait for deployment, then open the URL shown in Settings > Pages. The project URL usually resembles https://YOUR-USERNAME.github.io/vizora-studio/
